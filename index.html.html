ภาคปลาย 2569 (บางเขน)

หลักสูตร ศศ.บ. ปรัชญาและศาสนา มหาวิทยาลัยเกษตรศาสตร์

บันทึกอัตโนมัติแล้ว (รีเฟรชไม่หาย)

รายการวิชาที่วางแผนลงทะเบียน 0 วิชา

เลือกหมู่เรียนเพื่อดูเวลาเรียนบนตารางและตรวจวันสอบอัตโนมัติ

หน่วยกิตรวมที่เลือก
0 หน่วยกิต

ตารางเรียนรายสัปดาห์ (08:00 – 21:00 น.)

แสดงคาบเรียนทั้งหมด (รวมทั้งบรรยายและปฏิบัติของหมู่ที่เลือก)

ปกติ เวลาเรียนทับกัน

สรุปตารางสอบกลางภาค และ สอบปลายภาค (ภาคปลาย 2569)

อ้างอิงจาก (ร่าง) ประกาศตารางสอบ ภาคปลาย 2569 และตารางสอบปี 2568 (กรณีรายวิชายังไม่อยู่ในร่างปี 69)

* ข้อมูลวันสอบเป็นค่าประมาณการ โปรดตรวจสอบประกาศทางการอีกครั้ง
รหัสวิชา / ชื่อวิชา หมู่ สอบกลางภาค (Midterm) สอบปลายภาค (Final) จัดการ

เพิ่มรายวิชาจากข้อมูลจริง (my.ku.th)

วิธีใช้งานง่าย ๆ:
  1. เปิดหน้าค้นหารายวิชาใน my.ku.th แล้วกดเลือกข้อความทั้งหมด (Ctrl+A แล้ว Ctrl+C)
  2. นำมาวางในช่องด้านล่างนี้ (สามารถวางต่อกันทีละหลายวิชาได้เลย)
  3. ระบบจะ รวมหมู่บรรยาย + ปฏิบัติ ที่เลขหมู่ตรงกันให้เป็นหมู่เดียว จัดหมวดหมู่ (ปรัชญาและศาสนา / GenEd) และดึงวันสอบให้อัตโนมัติ
